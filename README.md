## Estado de este texto: borrador en revisión

Este manuscrito pasó por una revisión crítica interna que obligó a corregir la coherencia de sus términos clave entre capítulos ("monólogo", "conocer" y "consecuencias"), varias atribuciones de pasajes y algunas lecturas exegéticas. Todas sus citas bíblicas fueron verificadas literalmente contra la Reina-Valera 1960.

Todavía no ha recibido una revisión teológica externa, y el autor sigue revisándolo durante la lectura. Por eso se publica como **borrador abierto a comentarios**, no como edición final. Si eres teólogo, pastor o lector con formación relevante y encuentras un error doctrinal, exegético o factual, por favor ábrelo como [*Issue*](../../issues).

## Qué es este libro

La oración no es una técnica para obtener cosas de Dios, sino la expresión de una relación que Él mismo inició. A partir de la Escritura, este libro recorre el diálogo entre Dios y el ser humano: la escucha, el lamento, la petición confiada y la intercesión, hasta descubrir que el propósito último de orar es conocerle y, un día, verle cara a cara.

Es un ensayo de teología bíblica escrito para el creyente que ora y para el lector formado que conoce las críticas a la oración como proyección o como técnica. Un apéndice recoge lo que la neurociencia, la psicología y la antropología han observado sobre la oración, con la frontera explícita entre lo que esas disciplinas pueden decir y lo que no.
